# CGT Analysis Skill

A Claude Code skill implementing constructivist grounded theory (CGT) methodology as a human-AI collaborative workflow.

**Status: Design phase** — mapping CGT methodology to computational architecture. No code yet.

## What This Is

A tool for qualitative researchers that implements Charmaz's constructivist grounded theory as an interactive human-AI workflow. Domain-agnostic: usable for any qualitative analysis project.

### Core commitments

- **Cyborg intelligence model** (Haraway 1991): Rigor and depth emerge from human-AI interaction, not from either alone
- **Built for researchers who are both social scientists and engineers** — rigorous enough for publication, engineered enough to actually build with
- **Creative spark architecture**: Designed around creating conditions for human abductive leaps — the creative reorientation that LLMs tend against
- **Scalable rigor**: Three levels (quick scan, working analysis, publication-quality) with different human-in-the-loop depths
- **Researcher voice preservation**: The researcher's own words and ideas are preserved alongside AI synthesis

### Why this matters

Current AI tools for qualitative analysis are widely described as inherently positivist (Chatzichristos 2025). But this conflates the epistemology of current implementations with the epistemology of the technology itself. A tool designed around constructivist principles — recursive iteration, researcher reflexivity, co-constructed meaning — can support rigorous CGT without positivist drift.
