# Design Memos

Research memos accumulated during the design and build of the CGT skill. Per our own recursive frame (CGT-on-CGT-design), these function as orienting commitments for the build but follow CGT memo practice — they accumulate, evolve, sometimes stabilize into categories, sometimes get revised or deprecated.

We're eating our own dogfood from move one: this is the same memo structure CGT projects built with the skill will eventually use.

## Status conventions

- **current** — active, orients work going forward
- **superseded** — replaced by a later memo (link the successor)
- **deprecated** — abandoned, kept for trace
- **parked** — flagged for later, not yet written up
