# Learning loops in the analytical process
*Status: current | Date: 2026-04-28*

Anywhere the workflow says "come back to this" or "the researcher should periodically reflect on X," build the loop into the system. Stale categories surface for revisiting; memos get re-presented when new data unsettles them; reflexivity prompts arrive at the right moment. The tool surfaces what needs revisiting; it doesn't ask the researcher to remember.

Pairs with memo 004 (learning loops that improve the tool). Both rest on: **researcher attention and memory are scarce.**
