# Compression bias
*Status: current | Date: 2026-04-28*

The AI is trained to take long input and produce shorter output that "captures" the gist — summarize, paraphrase, key-points, abstract. That's its default information shape. For CGT, the default is corrosive: in-vivo language gets paraphrased away (the participant's actual words become the AI's words), specificity becomes generality (what made the data distinctive disappears), tensions get smoothed into tidy summaries, multi-voice gets harmonized into a single account, nuance gets compressed in the name of clarity. The JMIR finding — "AI flattens nuanced connections" — is partly compression bias in action.

What we want: preserve specificity by default. Quote in vivo, exactly, not as paraphrase. Surface structured material without summarizing it. Expand where expansion serves the analysis — more detail, more texture, more voices, not less. Compression is a move the researcher invokes when it serves the analysis, not a default the tool applies.

Compression operates as a meta-pattern across the directional gravities (memo 010): it's how theming flattens, how narrative coherence smooths, how authoritative summary erases uncertainty. Naming it as its own gravity lets the tool see and resist it across surfaces, not just at one move. The careful working register (memo 013) is part of what counters it — rushed AI compresses harder.
