# Characters as Subjects, Actions as Verbs (de-nominalize)

**Genres:** ALL — universal craft, not genre-scoped
**Rescoped:** 2026-08-07 (June: "Williams style craft should be for ALL writing." Originally tagged `gra-memory-creation`; de-nominalization is general craft. The GRA-specific example below — locating authority in an abstraction — is retained as the sharpest illustration, not as a scope limit.)
**Category:** register / pre-draft tilt
**Added:** 2026-07-04 (gra-memory-creation genre build, T2)

## The Move

A nominalization turns an action into a noun and hides who did it: "the R3 collapse," "the
metabolism process's flattening," "the architecture's refusal." Turn it back into a real subject
doing a real action: "when we collapsed revision into one owned move," "when the metabolism process
flattened the distinction," "when June rejected the exemption." This is Williams' de-nominalization
craft move, applied to GRA's specific failure: locating authority in an abstraction instead of a
person, a recorded ask, or a lineage.

## The Sharpest Case: Never Locate Authority in an Abstraction

The single most damaging version of this failure (skill §1g, `METABOLISM_LOG.md #24`): "the
architecture refuses it" makes an abstraction the agent of an authority claim, and in doing so
glosses out the real theoretical basis — the exact opposite of a real character doing a real
action. June, on R7: *"There's a theoretical point that is being glossed out of the memory through
a tendency to appeal to authority."*

The flagged draft read: **"which is exactly what this architecture refuses."** The fix is not to
soften "refuses" — it's to name whose position, which recorded ask, which theoretical lineage is
actually doing the refusing. "GRA refuses X" should become something like "June's C7 grounding
(Haraway's god-trick) is why this record doesn't state X as a flat fact" — the abstraction replaced
by the actual position and its source.

## Should / Shouldn't

- **Shouldn't:** "The system enforces never-naked framing." / "The values file requires situating
  context." / "Which is exactly what this architecture refuses."
- **Should:** "June's never-naked rule (WORKSHOP_LOG S29) is why this claim carries its stance
  field." / "C17 — context is carried but always partial — is why this record doesn't claim
  completeness."

## Watch the Mirror Failure

Don't let this harden into a reflexive anti-abstraction tic. A spec can legitimately say "the genre
must..." — that's a design commitment, not a glossed authority claim. The check is: is there a real
party, ask, or lineage this sentence could name instead of the abstraction? If genuinely not (a
structural design commitment with no single author), the abstraction is fine. If yes, name it.

## Why It Works

Nominalizations and abstraction-as-agent are the generative-side twin of the label-without-
descriptor lint (`writing_check.py`'s regex check): both let a claim's real basis go unstated. This
move prevents the failure at drafting time, before a lint has anything to catch.
